# Contributing to FLAMORIS Logging

Issues are welcome from everyone. Pull requests are accepted only from repository collaborators. Please open an Issue to propose fixes, API changes, or documentation changes.

Keep changes focused on reusable logging mechanics. Application state, product behavior, remote telemetry, and monitoring platforms belong elsewhere.

For substantial behavior or public API changes, open an Issue first. Pull requests should include deterministic tests, document compatibility impact, avoid unnecessary dependencies, and preserve the fail-safe contract.

Contributions are submitted under Apache License 2.0 unless stated otherwise.

## 日本語

Issueはどなたでも歓迎します。Pull Requestはリポジトリのcollaboratorのみ受け付けています。修正、API変更、ドキュメント変更などの提案はIssueからお願いします。

変更は再利用可能なログ機構に絞ってください。アプリ固有の状態、製品挙動、remote telemetry、監視platformは対象外です。

大きな挙動変更や公開API変更は、先にIssueで相談してください。Pull Requestには決定的なテストを含め、互換性への影響を説明し、不要な依存関係を追加せず、fail-safe契約を維持してください。
